2026.08.09

核心架构升级
核心架构v1.1.0

多 Thread 并发任务运行时

从单任务状态升级为真正可扩展的多任务 Agent Runtime。
  • 新增 task-runtime-manager.js，使用 Map<threadId, TaskState> 管理每个任务。
  • 第一版最多同时运行 2 个任务；第三个及以后自动进入队列。
  • Turn 完成、停止或失败后，队列中的下一个任务自动启动。
  • Agent delta、命令、Diff、审批、计划、Token、错误和 Turn 生命周期均按 Thread / Turn 路由。
  • 后台任务继续运行，切换历史任务不会中断其他任务。
  • Stop、Approval、Diff、Command 和附件临时文件按任务隔离。
  • 同一项目存在并行任务时显示冲突风险提示，暂不自动创建 Git Worktree。
  • app-server 重连时逐个恢复已知 Thread，无法确认的原 Turn 会明确标记失败。
  • 修复审批请求与 turn/start 返回交错时的状态竞态，并增加 Item 校验。
Task Runtime、队列和路由冒烟测试通过
文档 / 发布Release Archive

把 DeepSeek Codex GUI 的全部重要更新整理成可检索、可切换主题的发布页。

  • 沿用客户端深色水墨、橙色强调、悟空主视觉、玻璃卡片和本地毛笔字体的龙珠主题风格。
  • 支持关键词搜索、类别筛选、版本筛选，以及 12 套七龙珠角色主题即时切换。
  • 使用项目内本地素材，支持直接双击浏览；响应式布局适配常规桌面和窄屏窗口。
  • 完成页面脚本、资源引用、筛选交互、主题切换、响应式布局和浏览器控制台检查。

稳定性Reconnect

Codex app-server 自动重连

连接中断后自动恢复，减少重新启动程序的需要。
  • app-server 退出或初始化失败后自动重连，采用指数退避并限制最长等待时间。
  • 连接中断时清理挂起请求和失效审批，正在执行的 Turn 明确显示失败。
  • 重连后自动尝试恢复 Thread，恢复失败时下一条消息自动创建新 Thread。
  • 应用退出时取消重连，避免后台残留进程或重启竞态。
